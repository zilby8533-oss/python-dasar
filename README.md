# Python Dasar

Praktikum Python Dasar berdasarkan tutorial Santrikoding (19 bab). Setiap bab dikerjakan dan di-commit secara bertahap.

## Rangkuman Materi

1. Pengenalan dan instalasi Python
2. Struktur dasar program: komentar, indentasi, fungsi main
3. Tipe data dasar: int, float, str, bool, None
4. Variable dan aturan penamaan
5. Konstanta dengan konvensi huruf kapital dan typing.Final
6. Operator aritmatika, assignment, perbandingan, dan logika
7. Control flow: if, for, while
8. Function: parameter, args, kwargs, lambda
9. List, tuple, dan set
10. Dictionary
11. Class dan object
12. Encapsulation
13. Inheritance
14. Polymorphism
15. Abstraction
16. Exception handling
17. File handling
18. Module
19. Package

## Cara Menjalankan

    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
